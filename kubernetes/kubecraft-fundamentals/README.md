# KubeCraft Course: Kubernetes Fundamentals

## What is this directory about?
This directory contains some files I created for the hands-on lab in KubeCraft's Kubernetes Fundamentals course. 

## What I learned from this course
- How to create a Pod using the kubectl command or manifest file.
- How to interact, edit, and manage the pod.
- How to make Kubernetes Deployment.
- Learned the self-healing aspect of Kubernetes.

## File Description
| File Name                | Description                                    |
|--------------------------|------------------------------------------------|
| my-nginx-pod.yaml        | a bare minimum manifest to create pod.         |
| my-deployment.yaml       | a manifest to create Deployment, contains 10 replicates of httpd server |
