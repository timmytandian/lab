# Python Practice Codebase

This repository contains two simple Python scripts for practice purposes:

## 1. Rectangle Area Calculator

- **Description:**  
    Calculates the area of a rectangle given two numbers as input (length and width).

- **Usage Example:**
    ```bash
    python rectangle_area.py 5 10
    # Output: Area of rectangle: 50
    ```

## 2. FIFO Queue Implementation

- **Description:**  
    Implements a FIFO (First-In-First-Out) queue. Takes the queue size and an array of commands (e.g., `enqueue`, `dequeue`) as input.

- **Usage Example:**
    ```bash
    python fifo_queue.py 3 enqueue 1 enqueue 2 dequeue enqueue 3 enqueue 4 dequeue
    # Output: [2, 3, 4]
    ```
